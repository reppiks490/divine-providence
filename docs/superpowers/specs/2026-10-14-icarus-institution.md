# ICARUS research institution

Approved objective: an unattended institution that discovers evidence, formulates
falsifiable hypotheses, challenges competing models, remembers failures, and
publishes an intelligence service. The user approved this vision and requested
no manual operation. Implementation and activation are in scope.

The first institution protocol uses the actual owned CSV corpus and three
official announcement feeds (Federal Reserve, ECB, SEC). Every dataset is bound
to its Git revision, archive member, and byte hash. Whole files are used;
oversized files are deferred, never tail sampled. Filename identity remains a
hint and bar prices remain CANDLE_PROXY research prices.

DAEDALUS owns feature construction, development splits, validation, selection,
and statistical diagnostics. Four existing model families compete on five
purged development folds. The final holdout is reserved and never evaluated.
Circular-shift controls, moving-block uncertainty, cost stress, temporal slices,
and a fixed feature-family ablation challenge the development winner. These
reuse development evidence and cannot establish a confirmed edge. ORACLE owns
typed falsifiable hypothesis generation and the research graph representation.

Official announcements enter the evidence graph with separate publication and
first-observation times. Their price effects remain untested: historical bars
cannot be relabeled as contemporaneously available event evidence. No artificial
confidence, plugin invocation, broker access, or market execution is introduced.

A daily bounded Actions job discovers changed sources and executes two unseen
source/protocol contexts. Memory retains both negative and promising outcomes,
including the exact protocol and scientific dependency versions. A timeout is
an interrupted attempt, eligible for bounded retries, never scientific rejection.
After the queue is exhausted, the institution watches for new source revisions
and announcements; it reports that state instead of manufacturing discoveries.

Collection has read permissions. A separate trusted-main publisher checks the
run identity, content hashes, authority, allowed data paths, and memory parent
before updating a data-only research-history branch without force. Prior memory
is consumed as bounded JSON, never checked out or executed. Incomplete runs keep
the last complete evidence available and publish a current failure receipt.

The existing private hosted dashboard gains a research view. Its data APIs are
versioned static JSON files on the public repository's research-history branch.
No daily chat, paid model call, new secret, or manual download is required.

Existing subsystem production/promotion/execution owners retain authority.
Other departments remain honestly described as engineering dependencies until
their real research contracts are exercised by this coordinator.
