# OPUS NON-3D MASTER HANDOFF

This package is the consolidated export of the accessible **non-3D** work built, researched, audited, documented, or used as source evidence across the project history recovered from ChatGPT Library.

## Scope

Included project families:
- **ICARUS / AEGIS / HELIOS**: handoffs, masterbuild packages, assurance and scientific-integrity reports, control-state history, duplicate receipts/suppression records, empirical qualification packages, ATLAS/bridge artifacts, implementation and research-hardening outputs.
- **OrderBlockPro reconstruction**: staged analysis, taxonomy, named-setup evidence, formal evidence model, event dataset, duplicate/provenance audit, and the screenshot evidence cluster used as source knowledge.
- **Trading / Pine / backtest sources**: accessible Pine/backtest materials, RATE–OMNI MYTHOS conversation archive, and legacy source inputs used in strategy work.
- **Research summaries**: six generic-titled summaries from the ICARUS/HELIOS research period that were recovered and retained.

## Explicit exclusion

All 3D-model / 3D-character work is excluded, including Character3D releases, Tripo3D/Meshy/Hitem3D-related material, 3D research, 3D release signatures/keys, and 3D reference media.

## Integrity / completeness notes

- Accidental duplicate copies created during export were removed only when the duplicate files had identical SHA-256 hashes and the same export index.
- Distinct Library artifacts were **not** content-deduplicated.
- Two Project-scoped text/code sources blocked raw-byte export but were recovered as text representations.
- Three Project-scoped Excel originals could not be exported as raw bytes or extracted text; they are listed exactly in `UNAVAILABLE_ORIGINALS.md`.
- `MANIFEST.csv` and `MANIFEST.json` contain SHA-256 hashes and sizes for every file physically present in this package.

## Suggested Opus ingestion order

1. Read this file and `UNAVAILABLE_ORIGINALS.md`.
2. Read the newest ICARUS/AEGIS engineering/research reports and the absolute/master handoff archives in `icarus_aegis_helios/icarus_aegis/`.
3. Read HELIOS transfer/handoff artifacts in `icarus_aegis_helios/helios/`.
4. Ingest `orderblockpro/` plus `orderblockpro/source_screenshots/` as a linked evidence corpus.
5. Read `trading/` and `source_inputs/` for strategy/source continuity.
6. Use the manifest hashes to verify transfer integrity.
