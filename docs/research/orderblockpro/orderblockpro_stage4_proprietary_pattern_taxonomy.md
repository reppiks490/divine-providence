## Important structural upgrade

The evidence now supports a more detailed model than “major block + minor liquidity + fortress.”

There appear to be **named composite configurations** built from those base objects:

- single major/minor structures,
- stacked mini-block structures,
- triple-block structures,
- Fortress-based composite structures,
- and possibly “Super Mini” variants.

This suggests the system has at least two layers:

**Layer 1 — primitives**
Major Order Blocks / Icebergs, Minor Liquidity Levels, Nano-Blocks, Fortresses.

**Layer 2 — composites**
Named combinations such as Mini-Monsta Triple Blocks, Monsta-Mini Blocks, and Monsta-Mini Fortresses.

## Refined hierarchy

A stronger working hierarchy now looks like:

1. **Context**
   - VWAP
   - POC
   - Value High / Value Low
   - NYSE Open
   - Previous Day High / Low
   - Close
   - POWERLINE
   - KEY LEVEL
   - numbered reference bands

2. **Primitive order-flow structures**
   - Major Order Blocks / Icebergs
   - Minor Liquidity Levels
   - Nano-Blocks / Price Rips
   - Fortresses / Mini Icebergs

3. **Composite configurations**
   - Monsta-Mini Blocks
   - Monsta-Mini Fortresses
   - Mini-Monsta Triple Blocks
   - possible Super-Mini family (pending direct confirmation)

4. **Price behavior**
   - penetration into zone
   - hold / base / stall
   - rejection or acceptance
   - expansion toward the next opposing structure
   - serial continuation through successively higher/lower structures

## Strongest current hypotheses to verify against narration

### Composite-strength hypothesis
The proprietary “Monsta-Mini” / “Mini-Monsta” names likely denote combinations of smaller structures whose overlap creates a stronger composite area than any one component alone.

### Context-confluence hypothesis
The strongest examples repeatedly overlap the composite structure with VWAP, POC, NYSE Open, POWERLINE, Value Area, or prior-day references.

### Destination hypothesis
Price often travels from a confirmed composite buy-side zone toward the next meaningful sell-side structure, and vice versa.

### Acceptance-vs-rejection hypothesis
The examples suggest the reaction is determined by how price behaves **inside** the zone, not simply by touching its outer edge.
