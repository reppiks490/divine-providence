This is visual evidence only and is not a statistical win-rate estimate.

## 3. Intermediate targets matter

The 30 Jul NQ example is particularly important because the decline from the upper sell block does not need to travel all the way to the largest lower major block to produce a meaningful move.

Visible intermediate structures include:
- green major/minor structures,
- cyan/blue liquidity structures,
- a labeled KEY LEVEL,
- session/context references.

### Working implication
Potential destination logic may be hierarchical:

1. nearest strong opposing liquidity cluster,
2. contextual key level / VWAP / POC / session reference,
3. larger opposing major block.

This is a more realistic model than assuming every reaction should target the furthest opposite block.

## 4. Opposing structures can fail or be accepted

The **21 Sep 2026 NQ** screenshot introduces a critical counterexample to a simplistic reversal model.

Observed:
- Price originates from a large lower blue/green buy-side complex.
- It rallies into/through a large yellow + magenta overhead structure.
- Instead of reversing decisively there, price continues substantially higher.

### Why this matters
Not every opposing structure should be treated as an automatic reversal.

A valid future rule set will need to distinguish:
- **rejection**
- **temporary stall**
- **absorption**
- **acceptance**
- **breakthrough / failure**

This is one of the most important additions in the entire screenshot collection because it prevents overfitting the model to curated successful reversals.

### Transcript questions created by this example
- What confirms that an opposing block has failed?
- Does a close through the structure matter?
- Is time spent inside the structure meaningful?
- Does the emergence of new same-side liquidity above it confirm acceptance?
- Is a failed sell-side structure subsequently support on retest?

## 9. Revised destination model

The screenshots now suggest three distinct post-contact outcomes.

### A. Reversal
Price contacts an opposing high-grade zone and rotates away.

### B. Rotation to an intermediate reference
Price rejects but first terminates or pauses at:
- a minor liquidity cluster,
- KEY LEVEL,
- VWAP,
- POC,
- value area,
- session reference.

### C. Acceptance / continuation
Price trades through the opposing structure and continues, potentially with new same-side structures appearing beyond it.

This three-outcome framework is more faithful to the screenshots than a simple “touch = reverse” model.
