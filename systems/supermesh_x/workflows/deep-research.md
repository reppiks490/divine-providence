# Deep research workflow

1. Define claims/questions and freshness requirements.
2. Resolve entities/identifiers.
3. Search primary + specialist + broad sources in parallel where useful.
4. Crawl/extract only the best candidate domains/pages.
5. Add academic/citation evidence when the question is scientific.
6. Normalize and deduplicate.
7. Build contradiction table and unresolved-gap list.
8. Verify consequential claims against primary sources where practical.
9. Produce synthesis with provenance and confidence.
