# Private Intelligence Event Overlay

1. Build the public event record and Shock Graph from public/structured sources.
2. Ingest relevant authorized email/newsletter/alert evidence into the private lane.
3. Retrieve authorized portfolio/account context only when the task calls for it.
4. Apply the private-source boundary before any external provider call.
5. Compute the portfolio shock overlay from observed shocks, not from political preference or unsupported causal assumptions.
6. Fuse public and private conclusions while keeping evidence IDs and permissions separate.
7. Never translate the analysis into a live trade without a separate, explicit brokerage action request and authorization.
