# OmniScout research workflow

Use for broad, difficult, or high-uncertainty research.

1. Convert the request into explicit claims/questions.
2. Build an entity/identifier map.
3. Generate query families and source-class waves.
4. Fetch authoritative structured/primary sources first.
5. Expand to independent web/search providers for discovery.
6. Crawl/extract only high-value domains/documents.
7. Add scholarly/citation or repository lanes when the subject calls for them.
8. Normalize timestamps, identifiers, units, and source families.
9. Build a claim ledger and contradiction table.
10. Run targeted gap queries only for unresolved high-value claims.
11. Stop on diminishing information gain.
12. Synthesize with provenance, caveats, and explicit unresolved gaps.
