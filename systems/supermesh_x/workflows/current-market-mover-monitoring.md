# Current Market-Mover Monitoring Workflow

This workflow tracks public communications/actions from market-moving people and institutions and evaluates market association without private surveillance or political persuasion.

## 1. Resolve the mover dynamically

Seed profiles may include Donald Trump and Elon Musk. All officeholder-dependent roles (central-bank leadership, Treasury/economic officials, energy/geopolitical officials) must be resolved at runtime from current authoritative sources. Executive roles should also be refreshed when material.

## 2. Acquire public signals

Preferred lanes:
1. direct public social/official source when available
2. official government/company/regulatory release
3. reputable breaking-news confirmation
4. search/crawl fallback
5. public video/transcript

Never request private messages, private location, non-public account content, or bypassed access controls.

## 3. Classify the event

Extract actor, timestamp, platform/source, topics, named assets/entities, action type, policy/geopolitical theme, surprise/novelty, and possible transmission channels.

For Iran/Strait of Hormuz events, explicitly check shipping chokepoints, sanctions, energy supply, military escalation/de-escalation, diplomacy, and crypto/sanctions-evasion channels.

## 4. Build the synchronized market panel

Collect the smallest useful set across equity indices, volatility, FX, rates, commodities/energy, sectors, and crypto. Normalize timezone, session, symbol mapping, bar interval, and availability time before comparison.

## 5. Measure the event

Calculate raw and abnormal returns, realized volatility, volume anomaly, cross-asset confirmation, peak response, decay/reversal, and pre-event movement. Use counterfactual controls where feasible.

## 6. Confounder scan

Search the same window for macro releases, central-bank actions, earnings, regulatory decisions, other geopolitical headlines, market open/close effects, and already-in-progress trends.

## 7. Score conservatively

Combine timing, source quality, novelty, magnitude, volume/volatility confirmation, cross-asset coherence, counterfactual fit, independent-source families, confounders, and anticipation. Output `inconclusive`, `plausible association`, `supported association`, or `strongly supported association`; never claim causality solely from timing.

## 8. Learn from outcomes

Store only non-sensitive public-event metadata, provider reliability, timestamp quality, affected asset classes, realized response shape, and attribution errors. Use this to improve routing and event-window selection, not to infer private behavior or political intent.
