# Research mesh

## Goal

Exceed any single search/scrape provider by federating multiple retrieval methods and source classes.

## Retrieval modes

- keyword/web search
- semantic search
- site mapping
- focused crawl
- direct URL extraction
- browser-assisted retrieval
- academic search and citation graphs
- news search
- regulatory/official databases
- repository/code search
- user files and connected workspaces
- structured public/private APIs

## Query lattice

For difficult research, generate multiple query families: canonical terms, synonyms, entities, identifiers, date constraints, adversarial/contradictory wording, primary-source targeting, and historical terminology. Deduplicate results by canonical URL/document identity and content similarity.

## Coverage expansion

Use breadth in this order:

1. exact primary-source lookup
2. specialist structured providers
3. broad search from multiple independent engines
4. crawl the most relevant domains/pages
5. academic/citation databases when evidence is scientific
6. archives or historical snapshots when chronology matters
7. browser interaction only when static retrieval cannot reach the required public content

## Contradiction engine

When sources disagree, store both observations with timestamps and identify likely causes: update timing, methodology, geography, unit, symbol mismatch, revision, source copying, or genuine dispute. Do not average incompatible facts.

## Research stop rule

Stop when the question is answered to the requested confidence, new sources are mostly duplicates, remaining gaps are disclosed, and further retrieval has low expected value.
