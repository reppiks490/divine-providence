# Coding and orchestration

SuperMesh-X coordinates but does not replace specialized coding disciplines.

## Roles

- Astral Orchestrator: model/worker routing when explicitly selected and available.
- Codex Coordinator: bounded ownership visibility for parallel Codex tasks.
- Superpowers: planning, TDD, debugging, review, verification, worktrees where applicable.
- Akinator: repository-wide knowledge evolution when installed and applicable.
- Baton Pass: compact cross-agent/session continuity.
- Founder Pulse: issue-flow/operations analysis for GitHub/GitLab when applicable.

## Rules

Use one owner per mutable surface. Parallelize independent work, not overlapping edits. External data tools are read-only by default with respect to the repository. Verification evidence outranks agent self-report.

## Handoff packet

Include goal, completed work, files/areas touched, verification performed, deviations, current blockers, next action, and next owner. Do not dump full transcripts.

## v2.5 pre-runtime isolation boundary
Future computer, terminal, or multi-agent workers must enter through the v2.4 admission reservation and the v2.5 workspace/remote-store contract. Keep host filesystem access deny-by-default, use explicit opaque mounts, enforce network egress at the runtime boundary, execute argv vectors rather than ambient shells, resolve secrets only through an authorized broker, and require remote ownership stores to preserve atomic CAS plus fencing. A control-plane policy decision is not itself runtime enforcement.
