# Forex Factory macro-calendar adapter

Use Forex Factory as a macro-event scheduling and release-observation source when lawfully accessible. Its public calendar can expose weekly exports in ICS, CSV, JSON, and XML.

Normalize: event name, currency, impact tier, scheduled timestamp, actual, forecast, previous, revision, related story links, original timezone, retrieval time, and source record identity.

The event engine must distinguish scheduled time from actual release/availability time. Revisions append instead of overwriting prior values. Surprise calculations are descriptive and asset-direction interpretation is event-specific; a positive numerical surprise is not universally bullish.

Join calendar events to the Event Fabric as competing/confounding events so a Trump, Musk, executive, geopolitical, or social-media event is not incorrectly credited for a move that coincided with CPI, payrolls, central-bank decisions, or another macro release.
