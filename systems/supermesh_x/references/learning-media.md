# Learning and media

## YouTube

When a supported YouTube transcript capability exists, extract timestamp-grounded claims and concepts. Build summaries, concept maps, comparison matrices, quizzes, study guides, implementation checklists, or artifacts grounded in the transcript.

## Study engine

Transform any evidence set into:

- prerequisite graph
- layered explanation (beginner → advanced)
- retrieval-practice questions
- misconceptions and counterexamples
- worked examples
- spaced-review prompts
- mastery checks

Study outputs must distinguish source facts from generated teaching analogies.
