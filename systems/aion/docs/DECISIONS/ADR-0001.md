# ADR-0001 — AION owns decision-time evidence and replay

Date: 2026-09-23. Status: implemented foundation, integration pending review.

## Decision

Create AION as a separate sibling repository with one source/clock/evidence contract, immutable forecast records, deterministic as-of replay, visibly synthetic scenario branches and read-only packets. Icarus retains order authority; DAEDALUS retains protected research and promotion; ATHENA remains advisory; ARGUS owns authenticated microstructure feature semantics.

## Why

The accessible Icarus repository already has paper replay, source collectors and a trade aggregator. Archived siblings establish separate research, state and microstructure contracts. Their available handoffs do not establish one shared answer to: “Which version of each source was actually available when this decision was made, and which later result settled that exact forecast?”

The Icarus `main` event window and its isolated ML branch use different rules for future macro observations. This is a concrete reason to centralize availability rules without claiming a fitted model consumed unreleased values. Similarly, macro observation periods, release dates and revisions differ; true order-book reconstruction needs venue sequences, snapshots and recovery.

## Consequences

- Every future integration requires a reviewed adapter and source attestation; declaration alone is insufficient.
- AION's chain and SQLite triggers detect ordinary mutation but are not a remotely attested audit log.
- The cockpit offers a compelling interactive demonstration while distinguishing observed, shadow and synthetic evidence.
- The first complete real-data milestone is a paired replay of one recorded session, with authenticated source clocks and later outcomes. Performance claims require separate research and forward evidence.
