# Agent Handoff Rules

This repository is a sibling machine in the Icarus intelligence stack. Preserve its boundary.

1. Inspect current code before extending it; do not restart from a new architecture.
2. Run the complete NEXUS test suite before and after changes.
3. Cross-system schema changes require reading the sibling's current contracts first.
4. Preserve raw identities, repeated timestamps, availability semantics and source sequence.
5. Never make CSV candle proxies look like true trade/depth/order-book evidence.
6. Do not move DAEDALUS validation/promotion, ATHENA supervision, AION evidence memory, ARGUS microstructure truth, or Icarus execution authority into NEXUS.
7. Use the authoritative full corpus before declaring corpus completion.
8. Record every new invariant as a test.
